# 8-bit CPU / ALU in Verilog

A beginner-friendly 8-bit CPU project built from separate Verilog modules and integrated through a top-level module. The design includes an ALU, control unit, registers, program counter, memory address register, RAM, instruction register, shared CPU bus, output register, and FPGA wrapper.

## Features

- 8-bit datapath and 4-bit address/program counter.
- Modular design using separate Verilog modules.
- ALU operations: addition, subtraction, bitwise XOR, and bitwise AND.
- Control unit with fetch/decode/execute sequencing.
- RAM initialized with a sample program and data.
- FPGA wrapper exposing the output register on 8 LEDs.

## Modules

| Module | Purpose |
|---|---|
| `ALU` | Performs arithmetic and logic operations |
| `ControlUnit` | Generates control signals and sequences CPU states |
| `ProgramCounter` | Holds the address of the next instruction |
| `MAR` | Holds the memory address |
| `RAM` | Stores instructions and data |
| `Instruction_Register` | Holds the current instruction and separates opcode/operand |
| `A_Register`, `B_Register` | Hold ALU operands |
| `CPU_BUS` | Selects a source for the shared datapath bus |
| `Output_Register` | Holds the externally visible output |
| `CPU_Top` | Connects the CPU modules together |
| `FPGA_Top` | Board-facing wrapper; maps output to LEDs |

## Instruction encoding

The instruction format is `[7:4] opcode` and `[3:0] operand`.

| Instruction | Opcode | Meaning |
|---|---:|---|
| LDA | `0001` | Load memory data into A |
| ADD | `0010` | Add memory data to A |
| STA | `0011` | Store A to memory |
| OUT | `0100` | Copy A to output register |
| SUB | `0101` | Subtract memory data from A |
| XOR | `0110` | Bitwise XOR with memory data |
| AND | `0111` | Bitwise AND with memory data |
| HLT | `1111` | Halt the control sequencer |

## How to simulate

1. Create a new RTL project in Vivado (or use another Verilog simulator).
2. Add every `.v` file in `rtl/`.
3. Set `FPGA_Top` as the synthesis top for an FPGA build, or `CPU_Top` as the simulation top.
4. Add a testbench that generates `clk`, pulses `reset`, and observes `output_data` and `HLT`.
5. Run behavioral simulation before programming an FPGA.

## Control Signals

The Control Unit generates control signals to coordinate instruction fetch, decode, and execution across the CPU modules.

### Control Signal Reference

| Signal | Meaning | Function |
|---|---|---|
| `CO` | Counter Out | Places the Program Counter value on the bus |
| `CL` | Counter Load | Loads the Program Counter from the bus |
| `CE` | Counter Enable | Increments the Program Counter |
| `MI` | MAR In | Loads the Memory Address Register |
| `RI` | RAM In | Writes bus data into RAM |
| `RO` | RAM Out | Places RAM data on the bus |
| `II` | Instruction In | Loads the Instruction Register |
| `IO` | Instruction Out | Places instruction data on the bus |
| `AI` | A Register In | Loads data into the A Register |
| `AO` | A Register Out | Places A Register data on the bus |
| `BI` | B Register In | Loads data into the B Register |
| `BO` | B Register Out | Places B Register data on the bus |
| `ALO` | ALU Enable | Enables ALU operation |
| `SUB` | Subtract Select | Indicates subtraction in the Control Unit |
| `XRA` | XOR Select | Selects bitwise XOR |
| `ANA` | AND Select | Selects bitwise AND |
| `EO` | ALU Out | Places the ALU result on the bus |
| `OI` | Output In | Loads the Output Register |
| `OO` | Output Out | Places output register data on the bus |
| `HLT` | Halt | Indicates that the CPU has halted |

### Instruction Execution Sequence

| Timing State | Operation |
|---|---|
| `T0` | PC → MAR |
| `T1` | RAM → IR |
| `T2` | Increment PC |
| `T3` | Decode instruction and load operand address into MAR when required |
| `T4` | Execute instruction-specific operation |
| `T5` | Perform ALU operation for ADD, SUB, XOR, or AND |
| `STOP` | Halt the control sequencer |

### Important Notes

- The CPU uses a shared 8-bit bus to transfer data between modules.
- Control signals determine which module drives the bus and which module receives data.
- Avoid enabling multiple bus sources simultaneously.
- `SUB` is generated by the Control Unit, while the current ALU instance uses the separate `SUB_SELECT` input. These signals should be connected consistently before claiming instruction-driven subtraction is fully functional.
- The execution sequence shown above describes the intended control flow; verify it with simulation before treating it as a validated timing table.
